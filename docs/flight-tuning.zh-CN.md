# 起飞后不稳：诊断与调参指南

本文面向 ANet Relay 平台的小型四旋翼（Pixracer 级飞控，PX4 或 ArduPilot，经 `mavesp8266` Wi-Fi 数传接入，无遥控器）。症状通常是：起飞后左右晃、往一个方向漂、上下起伏、原地打转。处理顺序是**先运行标定流程，再判断飞行模式与定位条件，再排查机械，最后调参**。不要一开始就改 PID。

配套功能：

- **标定流程**（v0.3.0 起）：检查器 **标定** 页按固定顺序完成链路、电池、参数、校准、电机、振动、悬停与阶跃响应检查，每项给出判定、数值、门限与处理建议，并保存为报告（第 1 节）。
- **飞行健康**：检查器 **概览 → 飞行健康** 在每次飞行中实时给出十项诊断（第 3 节）。标定流程的悬停测试使用同一套统计与门限。

## 1. 先运行标定流程

### 1.1 启动

1. 选中飞机，打开检查器 **控制** 页，在起飞前检查下方点击 **运行标定检查**（或直接切到 **标定** 页）。
2. 先附身飞机（操作员持有控制权），飞机须已上锁、位于地面、链路正常。
3. 选择流程后点击 **启动流程**。流程逐步推进；需要人确认的步骤会显示提示，危险步骤在真机上需要输入确认词。任何时候都可以点击 **中止**：电机测试立即停止，空中的飞机自动降落。急停优先于流程。

| 症状或目的 | 推荐流程 | 包含步骤 | 约耗时 |
|---|---|---|---|
| 新机首飞、换过飞控或电机、问题原因不明 | `full_bench` 完整标定与测试 | S1–S12 | 约 6 分钟 |
| 每天第一次起飞前 | `preflight_quick` 快速起飞前检查 | S1、S2、S7、S9（悬停 10 秒）、S12 | 约 1.5 分钟 |
| 起飞即翻、原地打转、怀疑电机接错 | `motor_check` 电机顺序与转向 | S1、S6、S12 | 约 1 分钟 |
| 嗡嗡声、高度乱跳、日志振动高 | `vibration_check` 振动 | S1、S7、S9（悬停 20 秒）、S12 | 约 1.5 分钟 |
| 机械已确认无误，只想调稳 | `hover_tune` 悬停与稳定性 | S1、S8、S9、S10、S11、S12 | 约 2 分钟 |

### 1.2 各步骤测什么

| 步骤 | 内容 | 判定依据与处理 |
|---|---|---|
| S1 链路与固件 | 心跳、飞控类型与版本、参数表、丢包与往返时延 | 丢包 ≥ 3 % 或往返 ≥ 120 ms 告警：靠近接入点，改用较空闲的信道 |
| S2 电池静息 | 静息时每节电压 | 低于告警或严重门限即判定：先充满电再测，否则 S9 的悬停油门与压降不可信 |
| S3 参数基线 | 机架、倾角上限、速率环增益、悬停油门、失控保护参数 | 超出推荐范围只告警，不修改；报告记录全部基线值，便于对比调参前后 |
| S4 传感器校准 | 陀螺、水平、气压计依次校准（真机确认词 `CALIBRATE`） | 校准期间保持飞机水平静止；任一项失败即判定失败 |
| S5 杆向 | 逐轴推杆，确认响应方向 | 只能由操作员确认 |
| S6 电机顺序与转向 | 按布局图逐个以 8 % 油门转动 1.5 秒（真机确认词 `MOTOR`，必须拆桨） | 回答"位置错误"或"转向错误"即判定失败：交换信号线或在输出映射中调整；转向错误交换任意两根相线或在电调中反转 |
| S7 地面振动 | 拆桨状态下全部电机以 10 % 转动 4 秒，以 10 Hz 记录振动 | 门限为飞行门限的一半（告警 7.5 m/s²，失败 15 m/s²）；出现加速度计削波即失败。ArduPilot 依次转动各电机，PX4 同时转动 |
| S8 装桨确认 | 装桨并检查桨向与紧固 | 只能由操作员确认 |
| S9 悬停测试 | 起飞至 0.6 m 悬停（默认 15 秒，可选 10–30 秒），测振荡、松杆倾斜、航向漂移、定高稳定性、悬停油门、电机输出差、振动与压降（真机确认词 `ARM`） | 与飞行健康同一套门限（第 3 节），报告给出窗口内均值与峰值。悬停失败时跳过 S10 |
| S10 阶跃响应 | 定高模式下对横滚、俯仰（±0.3 杆量 0.4 秒）与偏航（±0.5 杆量 0.6 秒）施加阶跃，测上升时间、超调、调节时间与残余振荡 | 见 1.3 |
| S11 悬停学习 | 以 S9 实测悬停油门给出飞控 `MOT_THST_HOVER` / `MPC_THR_HOVER` 与 Relay `calibration.hover` 的建议值 | 逐项选择"应用"或"保留"；写入飞控参数需输入参数名，写入后回读校验 |
| S12 报告 | 汇总判定 | 任一步失败则流程失败；只有告警则为"有警告" |

### 1.3 阶跃响应的判读

各项时间以响应自身的稳定值归一化，不受飞控杆量到角度换算的影响：

- **超调** > 25 % 告警，> 45 % 失败：速率环 P 偏高，建议下调 10 %。
- **残余振荡**：松杆 0.3 秒后仍有超过 15 % 的来回摆动：P 或 D 偏高，建议 P、D 各下调 10 %。
- **上升时间**（10 %–90 %）横滚、俯仰慢于 0.3 秒、偏航慢于 0.4 秒：P 偏低，建议上调 10 %。
- **响应反向**：直接失败，检查杆向（S5）与飞控安装方向。

涉及的参数：ArduPilot `ATC_RAT_RLL_P/D`、`ATC_RAT_PIT_P/D`、`ATC_RAT_YAW_P`；PX4 `MC_ROLLRATE_P/D`、`MC_PITCHRATE_P/D`、`MC_YAWRATE_P`。**建议从不自动写入。** 在 **参数** 页逐项修改后再运行一次 `hover_tune`，对比两份报告；每次只改一项。

### 1.4 报告

流程结束后 **标定** 页显示报告：每步判定、数值与门限、发现与建议修改，可 **导出 Markdown**（中英文表格，可直接粘贴到工单）或 **导出 JSON**。全部报告保存在 **记录** 工作区的"标定报告"分组中，Relay 重启后仍可查看。

智能体同样可以运行标定流程（MCP `device_procedure_*` 工具或 SDK `procedure_start`，接口见 [`agent-api.zh-CN.md`](agent-api.zh-CN.md)）。真机上杆向、电机与装桨确认只能由操作员在 Relay 窗口完成；有人附身时，智能体启动的流程暂停，交还控制并上锁后继续。

## 2. 先确认期望：没有定位源时，"悬停"是什么样

| 条件 | 飞行模式 | 能保持什么 | 不能保持什么 |
|---|---|---|---|
| 仅 IMU + 气压计（本平台默认） | PX4 `ALTCTL` / ArduPilot `ALT_HOLD` | 姿态、大致高度 | **水平位置**：松杆后仍会随气流、重心偏差缓慢漂移，这是正常现象 |
| 加装光流 + 下视测距 | PX4 `POSCTL` / ArduPilot `LOITER` 或 `FLOWHOLD` | 姿态、高度、水平位置 | — |
| 室内动捕 / UWB / 外部定位 | `POSCTL` / `LOITER`，可用 `goto` | 全部 | — |

要点：

- **不要在自稳模式（ArduPilot `STABILIZE`，PX4 `STABILIZED`、`MANUAL`）下评估稳定性。** 自稳模式只稳定姿态，油门直接给推力，杆量一点抖动就会上下窜；固定的“悬停油门”会随电池电压下降而掉高。平台随附的 `keyboard_rc_controller.py` 正是在自稳模式下按固定油门定时起飞，飞过它之后飞机会停留在自稳模式。Relay 在地面接管飞机且检测到气压计时，会把自稳模式切到定高模式（空中接管不改模式）；技能和动作序列也使用定高模式。
- 没有位置源时，Relay 的"前进 1 m / 后退 1 m"是**开环估算**：按倾角与时间积分推算距离（误差通常在 ±30% 以内），飞控本身并不知道飞了多远。要精确的 1 m，需要光流 + 测距模块（例如 MTF-01、PMW3901 + VL53L1X 组合），装好后机体获得位置估计，Relay 自动改用闭环 `goto`。
- 新手常把"水平漂移"误判为"不稳"。区分方法：看 **飞行健康** 中的"姿态振荡"。振荡正常而只是缓慢漂移，属于第 1 行的预期；振荡数值高，才是真正的不稳。

## 3. 用飞行健康面板定位原因

在 Relay 中选中飞机，打开检查器 **概览**。起飞并在空中停留约 2 秒后开始评估，统计最近 5 秒，每次解锁重新计算。

| 项目 | 含义 | 常见原因 | 处理 |
|---|---|---|---|
| 姿态振荡 | 横滚、俯仰角速度的均方根（°/s）。悬停时健康值通常 < 10 | 桨叶 / 电机座 / 机臂松动；角速度环 P、D 过高 | 先紧固机械；再将 PX4 `MC_ROLLRATE_P/D`、`MC_PITCHRATE_P/D` 或 ArduPilot `ATC_RAT_RLL_P/D`、`ATC_RAT_PIT_P/D` 下调 10–20%，或执行自动调参 |
| 松杆倾斜 | 摇杆回中时飞机仍保持的倾角（°） | 水平 / 加速度计校准不准；重心偏；飞控装歪 | 在水平面重新校准加速度计和水平；电池居中；确认飞控箭头朝前且安装端正 |
| 航向漂移 | 偏航杆回中时的平均旋转速度（°/s） | 电机转向或正反桨装错；电机歪斜；罗盘干扰 | 对照机架图检查电机序号、转向、桨叶方向；重新校准罗盘 |
| 定高稳定性 | 定高模式下垂直速度的离散度（m/s） | 气压计受桨下洗气流 / 光照影响；离地太近（地效） | 用开孔海绵遮盖气压计；悬停高度 ≥ 0.5 m；加装下视测距。最后再考虑下调 PX4 `MPC_Z_VEL_P_ACC` / ArduPilot `PSC_ACCZ_P` |
| 悬停油门 | 悬停所需油门（%） | > 70%：机体偏重或电池电压低；< 20%：悬停推力参数与实际不符 | 减重或换电池；将 PX4 `MPC_THR_HOVER`、ArduPilot `MOT_THST_HOVER` 设为实际值（ArduPilot 可设 `MOT_HOVER_LEARN` = 2 自动学习） |
| 电机均衡 | 各电机平均输出的最大差值（µs），以及触顶比例 | 某角偏重；某支桨损伤或装反；电机 / 电调性能下降 | 面板会给出输出最高的电机序号：调整重心、换桨、检查该电机 |
| 振动（峰值） | VIBRATION 消息的振动峰值（m/s²）与加速度计削波次数 | 桨叶不平衡；飞控未减震；机架松 | 桨叶动平衡或换新；飞控用减震垫 / 减震球；紧固机架。出现削波必须先处理再飞 |
| 电池压降 | 解锁前静置电压与飞行最低电压之差，按每节计算（V） | 电池老化、未充满、放电倍率不足 | 换充满电、倍率更高的电池 |
| 链路 | 丢包率与往返延迟 | Wi-Fi 信号弱、2.4 GHz 拥挤 | 靠近接入点；优先 5 GHz 网络作为团队网络；减少同频流量 |
| 摇杆数据流 | 手动飞行时本机发出的杆量更新频率与最大间隔 | 窗口在后台被节流；无线手柄节能；电脑负载高 | 保持 Relay 窗口在前台；关闭手柄节能；关闭高负载程序 |

阈值是粗略的，用来指向原因，不替代飞行日志分析。

## 4. 机械与装配检查（最常见，先做）

无桨状态下完成：

1. **电机序号与转向**：运行 `motor_check`（标定流程 S6），按布局图逐个确认序号与转向（PX4 Quad X / ArduPilot `FRAME_CLASS` = 1、`FRAME_TYPE` = 1 时的标准顺序；六轴、八轴按飞控报告的机架绘制）。也可以用检查器 **控制** 页底部的电机测试或地面站的电机测试单独转动某个电机。
2. **桨叶正反**：正桨装在逆时针电机上、反桨装在顺时针电机上（以机架图为准）。装反的典型表现是起飞即翻或疯狂打转。
3. **飞控方向**：箭头朝机头；如果不是，设置 PX4 `SENS_BOARD_ROT` / ArduPilot `AHRS_ORIENTATION`。
4. **紧固**：电机座螺丝、机臂、飞控固定。手持机体轻摇，不应有任何松动声。
5. **重心**：电池放在机体几何中心；用两根手指托住对角电机，机体应基本水平。

## 5. 传感器校准

1. **陀螺、水平与气压计**：标定流程 S4 依次完成这三项（飞机放在真正水平的面上保持静止）。完整的加速度计六面校准仍需在地面站中进行；在 PX4 中再做一次 "Level Horizon"，在 ArduPilot 中执行 "Calibrate Level" 与 S4 的水平校准等效。
2. **罗盘**：远离金属与电源线后校准；室内磁干扰大时，ArduPilot 可考虑 `EK3_SRC1_YAW` 使用陀螺积分（需了解风险后操作）。
3. **气压计**：用开孔海绵遮挡，防止桨下洗气流直吹和强光照射。

## 6. 调参（在前面各步都正常后再做）

- 悬停油门先用 S11 悬停学习写入，再调速率环。
- 优先使用飞控自带的自动调参：PX4 `MC Autotune`（1.14 起），ArduPilot `AUTOTUNE` 飞行模式。自动调参需要较大空间和稳定的定高，室内小机建议在安全网内进行。
- 手动调参每次只改一个参数，幅度 10–20%，每次改完运行一次 `hover_tune`（或在定高模式悬停 20 秒观察"姿态振荡"），用报告对比修改前后的超调、残余振荡与上升时间。
- 高频抖动（嗡嗡声、电机发热）：降低 D；低频摇摆（慢速来回晃）：适当提高 P 或 I。
- 参数可以在 Relay 检查器的 **参数** 页搜索并修改，修改会记录到事件日志。

## 7. 无遥控器带来的特殊点

- Relay 以 50 Hz 发送杆量（PX4 `MANUAL_CONTROL` / ArduPilot `RC_CHANNELS_OVERRIDE`）。飞控只在 `COM_RC_LOSS_T`（PX4）/ `RC_OVERRIDE_TIME`（ArduPilot）内保持最后一帧杆量，链路短时抖动会表现为一瞬间"松手"。"链路"和"摇杆数据流"两项可以直接反映这一点。
- 手柄死区：手柄摇杆回中不准会持续给出小杆量，表现为"漂移"。在 **设置 → 手柄** 中查看实时杆量并调大死区。

## 8. 需要进一步分析时请提供

1. 最近一次标定流程的报告（**记录 → 标定报告**，导出 Markdown 或 JSON）。
2. Relay **记录** 工作区中该次飞行的 **导出 CSV** 文件（包含姿态、油门、杆量与事件）。
3. 飞控日志：PX4 的 `.ulg`（SD 卡 `log/` 目录），ArduPilot 的 `.bin`（SD 卡 `APM/LOGS/`）。
4. 机型信息：轴距、电机 KV、桨叶尺寸、电池节数与容量、起飞重量。
5. 飞行健康面板截图（处于"注意"或"异常"状态时）。
