# 09 · v0.5.2：Copilot 复制与排版、实验室实时试飞、动作序列油门参数、全部允许

日期：2026-11-09（UTC）。基线：v0.5.1 之后的 main（fee292c）。

## 0. 来源

操作员试用 v0.5.1 后提出：

1. Copilot 要能复制粘贴；
2. Copilot 的 Markdown 渲染要正常，尤其是表格；
3. 实际最常用的是“控制 → 动作序列”。期望序列为“起飞、到 2 m 悬停、降落”，但序列里不好改参数，实际会因油门不够而飞不起来、悬停不住。实验室能写出脚本、也能部署，但部署后没有解锁，飞机不动。希望实验室里写完脚本能实时测试、像控制队列一样随时调参；
4. Copilot 要能控制并完成这些调试、开发与测试；
5. 加一个“全部允许”的开关，不必每次点批准；
6. 完成后发布 0.5.2。

第 3 条的根因：程序只输出杆量，从不解锁；飞机未解锁时后端丢弃程序的输出（`programs/service.py::_write`）。实验室的“运行”页没有解锁入口（Copilot 的 MCP 部署工具有，界面没有），所以部署后程序一直在地面等待。

## 1. Copilot 复制与排版

- 对话区可选择文本（`data-selectable`），按钮保持不可选，拖选只得到文字。
- 所有 Relay 窗口右键菜单：输入框提供剪切、复制、粘贴、全选；有选区时提供复制（`electron/menu.mjs::editContextMenu`）。
- 每条回复下方有复制按钮（复制 Markdown 原文）；代码块复制代码；表格复制为制表符分隔文本。
- Markdown 渲染（`web/src/copilot/markdown.tsx`，GFM 子集，全部生成 React 元素，不注入 HTML）：标题、段落（软换行即换行）、有序/无序/嵌套/任务列表、表格（列对齐、单元格内行内格式与 `<br>`、过宽横向滚动）、围栏代码、引用、分隔线；行内粗体、斜体、删除线、代码、链接（仅 http(s) 与 mailto，在系统浏览器打开）、裸 URL。流式输出时未闭合的代码块按代码显示。中文紧邻的 `**粗体：**` 照常识别；`snake_case` 与 `2 * 3` 不误判为斜体。

## 2. 实验室实时试飞

- 部署接口 `POST /vehicles/{id}/program` 增加 `arm`、`confirm`：程序就位后切换到 STABILIZE（PX4 为 STABILIZED）并解锁；真机须 `confirm: "ARM"`，并在任何改动之前检查（缺确认词或预检不过时直接拒绝，不部署）。飞控拒绝解锁时部署保留，应答 `arm {ok:false, code, reason}`。部署已校验调用者，因此操作员无需先附身。
- 由部署解锁的飞机（`armed_here`），程序在地面停止时自动上锁；被新版本替换时这一职责转给新部署。
- `ctx.disarm()`：程序请求在本帧后上锁，仅当着陆状态为 `ground` 时执行，空中拒绝并记录一行日志。
- 飞行中部署新版本：新程序在同一次舰队线程调用中接管，空中无缝替换（测试 `test_a_new_revision_takes_over_in_the_air`）。
- 界面：运行页增加“解锁并启动”开关（缺省开启，按观看者记忆），真机弹出 ARM 确认；飞行检查器的“程序”组沿用同一偏好。参数页的实时调参不变。
- 新内置程序 `takeoff_hover_land`：起飞到 `target_alt`、悬停 `hold_s`、以 `descent` 降落并 `ctx.disarm()`；`hover`、`climb`、`kp/kd/ki/kv` 均可实时调；`learn` 打开时地面逐步加油门直到离地，悬停时积分修正。空中部署时直接进入爬升/保持。

## 3. 动作序列油门参数

- 没有定位估计的飞机在定高模式下用油门杆执行序列。`tuning {climb, hover}`：`climb`（0.55–1，缺省 0.72）为离地与爬升杆量，`hover`（0.35–0.65，缺省 0.5）为保持高度的杆量中心；接近、下降、落地缓冲杆量随 `hover` 平移；`climb ≥ hover + 0.05`。
- `POST /plan` 接受 `tuning`；`PATCH /vehicles/{id}/plan/tuning` 在飞行中修改，序列的技能与序列共享同一字典，正在执行的步骤立即生效；最后一步留下的悬停与取消后的悬停同样生效。事件 `plan_tuned`。
- 有定位估计时不应用（起飞与悬停由飞控完成，移动杆量中心只会让 POSCTL 漂移）。
- 界面：序列块下方“油门”面板（起飞爬升、悬停保持两个滑块与恢复默认），已解锁时显示实时读数：高度、爬升率、油门杆、电机输出。设置按观看者记忆。

## 4. 全部允许

- Copilot 配置 `autoApprove`（缺省关闭，只接受布尔值）。开启后真机命令不再弹出审批，但仍在对话中记录为“已自动批准”（事件 `approval` 带 `auto: true`，随即 `approval_closed reason=auto`），不闪烁窗口。
- 入口：审批卡片上的“全部允许”（开启并批准当前命令）；设置 → Copilot → 全部允许。开启期间 Copilot 标题栏常驻红框“全部允许”标记，点击关闭。每次门控调用时读取，切换无需重建会话。
- Relay 自身的保护不变：预检、操作员的“允许在这架飞机上运行程序”（仅操作员、每次连接重置）、附身优先、急停。

## 5. Copilot 与智能体的覆盖

- Copilot：`relay_plan` 接受 `tuning`，新工具 `relay_plan_tune`（`full` 等级，真机须批准）；`program_deploy` 接受 `arm`（批准即确认词）。程序指南补充 `takeoff_hover_land`、`ctx.disarm()`、`arm` 部署与空中换版本。
- 飞行 MCP：`relay_plan` 接受 `tuning`，新工具 `relay_plan_tune`（共 21 个，`sticks` 等级下仍为 13 个）。SDK：`plan(..., tuning=)`、`plan_tune()`、`program_deploy(..., arm=, confirm=)`。
