# 14 · v0.6.2：时间轴改为飞行计划

本文是 0.6.2 的设计契约。0.6.1 把摇杆时间线做成了独立工作区（`13`），实际使用中发现方向偏了。

## 1. 为什么改

真机上要调的不是摇杆，而是任务：起飞多高、往哪飞多远、多快、到位后等多久、然后降落。0.6.1 的时间轴编辑的是
油门、俯仰、横滚、偏航四条杆量曲线，离这个需求隔了一层；而“起飞 → 移动 → 降落”这类分步计划（`03` §5.8）只能在
控制页点内置计划，或者由智能体通过接口下发，没有地方让人编辑、调参、保存。

0.6.2 起，时间轴工作区缺省编辑**飞行计划**：一串任务步骤和它们的配置。摇杆时间线保留，放在文档栏最左边的
“计划 | 摇杆”开关后面（`Alt+K`），两者各有自己的文档、选择和撤销。

目标链路：写计划 → 模拟机上执行 → 看结果改参数再执行 → 真机执行 → 按名称保存，之后由人或智能体直接调用。

## 2. 工作区

自上而下：

| 区 | 内容 |
|---|---|
| 文档栏 | 计划/摇杆开关；“打开”菜单（已保存的计划、内置计划、模板、最近的执行、导入导出）；名称；保存；缺省速度与稳定时间；步数与估计总时长；撤销重做；步骤/分屏/代码视图；按键表 |
| 舞台带 | 精简的三维舞台；俯视路径预览；实时数值；安全区是否够用 |
| 执行栏 | 目标飞机、控制权、执行、不限安全区执行、从第 N 步、先复位（模拟机）、状态。需要确认的事在这一栏里问，不弹窗 |
| 时间条 | 每个步骤一个块，宽度按估计用时，始终铺满窗口宽度；下面是计划高度（点线）、本次实际高度（实线）、上一次执行（虚线） |
| 步骤表 | 每步一行：动作、各项配置、估计用时或实际用时、上次执行的结果、备注；底部是添加步骤和前移、后移、复制、删除 |
| 代码 | 同一份计划的文本形式，分屏时在右侧 |

- 步骤：起飞 `takeoff`、移动 `move`、前往 `goto`、悬停 `hover`、转向 `yaw`、降落 `land`、返航 `rtl`。
- 配置：`takeoff` 的高度；`move` 的前、左、上；`goto` 的 x、y、z、航向；`hover` 的秒数；`yaw` 的角度；
  `takeoff` / `move` / `goto` 还可以各自带速度和稳定时间，不带时用计划的缺省值，计划也不带时用飞机自己的缺省值。
- 估计用时按限速飞法（`12` §4、`13` §9）算：水平按限速和 0.5 m/s² 加减速，垂直 0.5 m/s，加稳定时间。它只用来
  排版和显示“约多少秒”，不是承诺；执行后该步显示实际用时。
- 俯视路径以起飞点为原点、起飞时的机头方向朝上。虚线圆是安全区允许的半径。`goto` 是本地坐标系里的绝对位置，
  选中有定位的飞机后才能画出来。
- 安全区：按路径离起飞点的最大距离（水平留 0.5 m）和最大高度算出计划需要的安全区，和当前设置比较。

### 2.1 按键

| 键 | 作用 |
|---|---|
| `Ctrl/⌘+Enter` | 执行（步骤表、代码、输入框里都有效） |
| `Ctrl/⌘+Shift+Enter` | 从选中的步骤开始执行（飞机须已在空中） |
| `Ctrl/⌘+Alt+Enter` | 不限安全区执行（§6） |
| `Space` | 取消计划，飞机原地悬停 |
| `Esc` | 取消选择；再按一次是全应用统一的停止（电机停转） |
| `← →` | 上一步 / 下一步，`Shift` 扩选 |
| `↑ ↓` | 改当前配置项的数值，`Shift` 大步长；多选时改每个选中步骤的同名配置 |
| `Tab` / `Shift+Tab` | 该步骤的下一个 / 上一个配置项 |
| 数字键、`Enter` | 直接输入数值 |
| `Alt+← →` | 步骤前移 / 后移 |
| `T` `M` `H` `Y` `G` `L` `R` | 在选中步骤后添加起飞、移动、悬停、转向、前往、降落、返航 |
| `Ctrl/⌘+D`、`Delete`、`N` | 复制、删除、编辑备注 |
| `Alt+T` / `Alt+S` / `Alt+C`、`Ctrl/⌘+E` | 步骤 / 分屏 / 代码视图；在步骤表和代码之间切换焦点 |
| `Ctrl/⌘+S`、`Ctrl/⌘+O` | 按名称保存；打开菜单 |
| `Alt+K` | 计划 / 摇杆 |

`Space` 和 `Esc` 的区别是有意的：计划可能飞在 10 m 高，`Space` 是“停下来悬停”，`Esc` 是全应用的紧急停止。

## 3. 代码视图

每行一步，`动作 名称 数值 名称 数值`，按列对齐：

```
# 室外测试
plan    10 m square
speed   2.5

takeoff  alt 10
move     forward 10
move     left 10       # 沿围栏
move     forward -10
move     left -10     speed 1
hover    5
land
```

- 开头可选：`plan <名称>`、`speed <m/s>`、`settle <秒>`、`frame flu|frd`。
- `hover 5`、`yaw 90`、`takeoff 10` 这种只写一个数的形式表示该步骤的主配置。
- 别名：`back` / `right` / `down`（对应负的 `forward` / `left` / `up`）、`wait`、`turn`、`return`。
- `#` 起注释；注释行和空行保留在原位置，随计划一起保存。
- 文本和步骤表是同一份文档：每次解析成功就替换文档；在步骤表里改动只重写变化的行。光标所在行选中对应步骤，
  光标在数值上时选中对应配置项。`Alt+↑↓` 改光标处的数字。
- 有问题的文本不会变成计划，也不能执行。每个问题指明行号和规则，例如“第 3 行：move 没有参数 sideways，可用：
  forward、left、up、speed、settle”。步骤表保持上一次有效的计划并变为只读。

## 4. 已保存的计划

`Ctrl/⌘+S` 把计划按名称保存到后端（数据目录的 `plans.json`），id 由名称生成（小写字母、数字、`-`、`_`）。
保存的内容是校验过的步骤和代码视图的文本（含注释）。

| 接口 | 说明 |
|---|---|
| `GET /plans/saved` | `{plans: [{id, name, description, steps, source, updated}]}`，最近保存的在前 |
| `PUT /plans/saved/{id}` | `{name?, description?, steps, source?}`；步骤按 `POST /vehicles/{id}/plan` 的规则校验；内置计划的 id 不可用 |
| `DELETE /plans/saved/{id}` | 删除 |
| `POST /vehicles/{id}/plan` | 新增 `saved: <id>`，与 `steps`、`builtin` 三选一 |

智能体侧：MCP 的 `relay_plan` 与 Copilot 的 `relay_plan` 接受 `saved`；`relay_plans_builtin` 同时列出已保存的计划；
SDK 有 `plans_saved()`、`plan_save()`、`plan_delete()` 和 `plan(saved=...)`。这样人在时间轴里调好的计划，智能体可以按
名称直接执行。

## 5. 执行

- 执行前自动做的事：空闲的模拟机自动附身；“先复位”打开时，上锁或坠毁的模拟机先回出生点。
- 在执行栏里询问的事：真机在地面解锁要输入 `ARM`；真机要先附身；飞机正由智能体控制时要确认接管；安全区不够时
  给出“调大并执行”和“不限安全区执行”。
- 执行中：时间条和步骤表标出正在飞的步骤，状态显示“第 2 / 5 步 · move forward 1 · 1.5 s”。每步结束后显示后端
  给的结果（`at 1.5 m`、`reached within 0.03 m`、`approach limit reached 0.43 m from the target`）和实际用时。
- 执行记录：每次执行记下计划文本、飞机、每步结果和用时，保留最近 12 次（本机浏览器存储）。计划改过之后可以
  从“打开 → 最近的执行”或执行栏的“回到上次执行的计划”取回。再次执行时，上一次的高度曲线以虚线保留。
- 后端：键盘的静止油门随飞行模式变化（底部、中位或悬停点），计划每一步切换模式时都会变，原来会被误判为
  “操作员接管”而中止计划（`13` §6 只处理了摇杆时间线）。现在键盘附身时：起飞在切换模式和解锁期间重新记录
  静止杆位；每一步开始后的 2 秒内，横滚、俯仰、偏航都居中而只有油门变化的输入视为新的静止位置。横滚、俯仰、
  偏航的输入任何时候都算接管；手柄不受这条规则影响。

## 6. 不限安全区执行

单独的执行入口（执行栏的“不限安全区执行”，`Ctrl/⌘+Alt+Enter`；安全区不够时的询问里也有）。

- 这次计划的各步不按安全区检查：`takeoff` 的高度、`move` 和 `goto` 的目标都不受限。设置里的安全区不变，
  计划结束（完成、失败、取消）后立即恢复。
- 只有操作员能用：`POST /vehicles/{id}/plan` 的 `unlimited: true`，智能体会话得到 `operator_required`。
  MCP、SDK、Copilot 不提供这个参数。
- 不受影响的：真机解锁的 `ARM` 确认、预检、操作员接管、限速飞行的监视（倾角、位置跳变、遥测过期、超速）、
  全部急停。
- 执行期间执行栏显示“无安全区”，`vehicle.plan.unlimited` 为 `true`，`plan_started` 事件带 `unlimited`。
- 计划步骤的高度上限从 10 m 提到 30 m（实际能飞多高由安全区决定，或由这个入口放开）。

## 7. 没有做的

- 实验室的机载程序仍然只输出摇杆，没有开放高层技能；航线类任务在时间轴里做。
- “记录”里的飞行记录没有带上计划文本，也不能从记录跳回时间轴；执行记录只在时间轴自己的“最近的执行”里。
- 计划里没有条件和循环，没有变量；步骤数上限 24。
- 拖动时间条上的块来改顺序或时长。
- 三维舞台卸载时浏览器控制台有一条 `removeChild` 错误（飞行工作区切走时同样出现），不影响使用，未处理。
